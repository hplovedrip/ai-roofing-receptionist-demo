# AI Roofing Receptionist Demo

A demonstration website showing how an AI receptionist can be used by a roofing business to handle and qualify initial website enquiries.

## Demo Features

The AI receptionist can:

- Speak with website visitors
- Understand common roofing enquiries
- Collect customer names
- Collect phone numbers
- Collect postcodes
- Collect property information
- Identify the roofing problem
- Assess enquiry urgency
- Create a structured lead summary
- Send the enquiry into an automated lead workflow

## Example Enquiries

The demonstration can handle enquiries relating to:

- Roof leaks
- Missing or slipped tiles
- Storm damage
- Flat roofs
- Chimneys and flashing
- Guttering and roofline
- Roof inspections
- Roof repairs
- Roof replacements
- New roof quotations

## Technology

The demonstration uses:

- HTML
- CSS
- JavaScript
- n8n
- AI language model integration
- Google Sheets
- Gmail automation
